# Salama Check-In
Private mental health and wellbeing check, nurse call-back, welfare navigator, and research database for the KDF pilot and the DCHS applicant and student pathway (NDU-Kenya).
Start with `docs/SETUP_GUIDE.md`. Analysis steps are in `docs/JAMOVI_GUIDE.md`. Everything in `sample_data/` is synthetic.

## Added later
- `kobo/` KoboToolbox forms, `tools/make_xlsform.py`, `tools/kobo_score.py`
- Anonymous sequential IDs (`issue_participant_id` in 01_schema.sql)
- Settings: situation, role change, simple view; optional `NURSE_SMS` in config.js
- `docs/RESEARCHER_HANDBOOK.md`

See docs/PORTAL_AND_LANGUAGES.md for the eight-tab portal and Kiswahili.
